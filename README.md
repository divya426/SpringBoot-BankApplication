# SpringBoot-BankApplication
This project is designed to demonstrate the implementation of a banking system using CRUD (Create, Read, Update, Delete) operations in a Spring Boot application. It covers building RESTful APIs to manage customer accounts, transactions, and basic banking operations with a focus on Java 17 and Spring Boot 3.x.

project structure:
Controller Layer: Handles HTTP requests and exposes REST APIs.
Service Layer: Contains business logic for banking operations.
Repository Layer: Interacts with the database using Spring Data JPA.
Entity: Represents database tables such as Customer and Account.

Features:
Create new customer accounts
Retrieve customer/account details
Update account information
Delete customer accounts
Basic transaction handling (deposit/withdraw)

Project Dependencies:
Spring Boot Starter Web
Spring Boot Starter Data JPA
MySQL Connector
Lombok 
Maven
